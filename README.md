# Plant Disease Prediction 🌱

Predicts plant diseases from leaf images using **Convolutional Neural Networks**.

## ✨ What It Does
- Classifies leaf images into disease categories
- CNN training with image augmentation
- Confusion-matrix evaluation

```bash
jupyter notebook
```
